# AMEEFramework 开发日志 - 2025-07-13

## 阶段总结

### 完成的功能模块

#### 1. 平台抽象层
- `IPlatformWindow` - 窗口接口
- `IPlatformContext` - GL 上下文接口 (原 IPlatformGLContext)
- `IPlatformLoop` - 游戏循环接口
- `IPlatformInput` - 输入接口
- macOS 实现: MacWindow, MacGLContext, MacGameLoop, MacInput

#### 2. 核心系统
- **Application** - 应用生命周期管理
- **Scene** - 场景管理 (Update/Render/灯光收集)
- **Entity** - 实体系统 (Transform + Components)
- **Component** - 组件基类 (Owner + Visibility)
- **Camera** - 相机组件 (内建 AspectRatio)
- **IDGenerator** - 唯一 ID 生成器
- **SingletonT** - 单例模板

#### 3. 资源系统
- **AssetManager** - 统一资源管理
- **AssetHandle** - 资源句柄 (Index + ID + Type + IsBuiltIn)
- **BuiltID** - 内建资源 ID 枚举
- **FileSystem** - 虚拟文件系统

#### 4. 渲染系统
- **RHI** - 渲染硬件接口抽象
- **RHIOpenGL** - OpenGL 4.1 实现
- **ShaderProgram** - Shader 编译/链接/Uniform
- **Mesh** - 网格 (VBO/VAO/EBO)
- **VertexLayout** - 顶点布局声明
- **Texture2D** - 纹理管理
- **Material** / **StandardMaterial** - 材质系统

#### 5. 光照系统
- **环境光** - Ambient Color
- **方向光** - Directional Light (Sun)
- **法线贴图** - Tangent Space + TBN 矩阵
- **高光反射** - Blinn-Phong

#### 6. 天空盒
- Cubemap 加载 (6张图 + 十字形切割)
- 全屏三角形渲染
- 地平线渐变效果
- 深度状态管理 (LEQUAL)

#### 7. 基础网格
- Cube, Sphere, Plane, Cylinder, Capsule
- 每顶点: position(3) + normal(3) + texcoord(2) + tangent(3) = 11 floats

---

## 关键技术决策

| 决策 | 说明 |
|------|------|
| OpenGL 4.1 | 跨平台兼容 |
| 全屏三角形天空盒 | 无需 VAO/VBO |
| CPU 预计算法线矩阵 | 性能优化 |
| 切线空间法线贴图 | TBN 矩阵 |
| 组件化架构 | 类似 Unity |

## Shader 命名规范

| 类型 | 前缀 | 示例 |
|------|------|------|
| Uniform | `u_` | `u_MVP`, `u_MainTex` |
| Vertex Input | `a_` | `a_Pos`, `a_Normal` |
| Varying | `v_` | `v_TexCoord`, `v_Normal` |
| Fragment Output | 无 | `fragColor` |

# 下一阶段：RT (Render Target) 系统

## 目标

实现离屏渲染，支持：
1. Shadow Map (阴影贴图)
2. 后处理效果 (Post-processing)
3. 反射探针 (Reflection Probe)

---

## 技术要点

### Shadow Map 流程

```
1. 从光源视角渲染深度
2. 存储到深度纹理
3. 主渲染时采样深度纹理
4. 比较深度判断是否在阴影中
```

### FBO 结构

```
RenderTarget
├── Color Texture (RGBA)
├── Depth Texture (D24/D32)
└── FBO ID
```
