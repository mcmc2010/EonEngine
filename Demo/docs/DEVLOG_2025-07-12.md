### 2. 资源管理系统

#### AssetManager
- 纹理加载/注册/卸载
- Shader 加载/注册/卸载
- Mesh 注册/卸载
- Material 注册/卸载
- Cubemap 加载（6张图 + 十字形切割）

#### AssetHandle
```cpp
struct AssetHandle {
    uint32_t Index = UINT32_MAX;
    uint64_t ID = ID_NULL;
    AssetType Type = AssetType::Texture;
    bool IsBuiltIn = false;
};
```

### 3. 内建资源系统

#### BuiltID 枚举
```cpp
enum class BuiltID : uint64_t {
    Shader_Default  = ...,
    Shader_Unlit    = ...,
    Shader_Skybox   = ...,
    Texture_White   = ...,
    Texture_Black   = ...,
    Texture_Normal  = ...,
    Texture_Default = ...,
    Texture_Missing = ...,
    Material_Default = ...,
    Material_Missing = ...,

};
```

#### 内建材质
| 材质 | Shader | 纹理 |
|------|--------|------|
| Default | Shader_Default (PBR) | 浅灰 + 法线 |
| Missing | Shader_Unlit | 粉色 |
| Skybox | Shader_Skybox | Cubemap |

### 4. 天空盒系统

#### 实现方式
- 全屏三角形（无 VAO/VBO）
- Cubemap 采样
- 地平线渐变效果

#### Shader
```glsl
// Skybox.vert
vec2 positions[3] = vec2[](
    vec2(-1, -1),
    vec2( 3, -1),
    vec2(-1,  3)
);
gl_Position = vec4(pos, 1.0, 1.0);
```

#### 加载方式
```cpp
// 6张图
LoadCubemap(rhi, "Assets/Skybox/");

// 十字形单图
LoadCubemapCross(rhi, "Assets/Skybox/1.png");
```

### 6. Shader 系统

#### 统一 Uniform 命名
| Uniform | 用途 |
|---------|------|
| `u_MainTex` | 主纹理 (Albedo) |
| `u_BumpMap` | 法线贴图 |
| `u_Color` | 颜色 |
| `u_Metallic` | 金属度 |
| `u_Smoothness` | 光滑度 |
| `u_Cubemap` | 天空盒立方体贴图 |

## 架构总览

```
┌─────────────────────────────────────────────┐
│  AMEEAppController (ObjC 桥接)              │
│    └─> DemoApp : MacosApplication           │
│          ├─ OnInit()    → 创建场景/实体      │
│          ├─ OnRender()  → 每帧渲染           │
│          └─ OnShutdown()→ 资源清理           │
├─────────────────────────────────────────────┤
│  AMEE::Application (基类)                    │
│    ├─ Init()    → 创建 Window/GLContext/RHI  │
│    ├─ Run()     → 启动 GameLoop              │
│    └─ Shutdown()→ 清理所有平台资源           │
├─────────────────────────────────────────────┤
│  AssetManager (单例)                         │
│    ├─ 内建资源 (Shader/Texture/Material)     │
│    ├─ 资源加载/卸载                          │
│    └─ Cubemap 加载                           │
├─────────────────────────────────────────────┤
│  Scene                                       │
│    ├─ 天空盒渲染                             │
│    ├─ 光照收集                               │
│    └─ 实体遍历                               │
└─────────────────────────────────────────────┘
```
